# Sistema Integrado de Saúde - Uíge

Protótipo em Python (UNIKIVI, Engenharia Informática) que simula a partilha
de dados entre unidades de saúde: registo de pacientes, histórico clínico e
transferência entre unidades.

## Como executar
python sistema_saude.py

## Limitações
Os dados ficam em memória e perdem-se ao fechar o programa.
